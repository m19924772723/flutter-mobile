# Dart 命令行工具 · 简介

> 用 Dart 写跨平台命令行工具

## 能做什么

- CLI 工具与子命令
- 文件处理
- 代码生成
- 跨平台脚本
- 编译为原生可执行

## 适合的项目

- **开发者工具**：跨平台
- **代码生成器**：模板产出
- **批处理工具**：脚本替代

## 本机环境

- 本机状态：⚠️ 需补装 Dart / Flutter
- 工具链：需装 Dart SDK（或 Flutter 自带）；args、path、pub
- 注意：⚠️ 需先装 Dart；可编译为原生可执行文件

## 快速开始

```bash
dart create -t console-full mycli
cd mycli && dart pub get
dart compile exe bin/mycli.dart
```
