# Dart 命令行工具 · 技术选型

## 推荐技术栈

| 用途 | 推荐 | 说明 |
|---|---|---|
| 语言 | Dart | AOT 编译 |
| CLI | args | 参数解析 |
| 文件 | path / io | 文件处理 |
| 包管理 | pub | 依赖 |
| 发布 | dart compile exe | 原生可执行 |

> 说明：上表为本机可落地的主流选型；「是否已安装」以各分类 README 的实测为准。

## 核心知识

- **参数解析**：args 库用法
- **异步 IO**：Future 与 Stream
- **AOT 编译**：原生可执行
- **pub 发布**：包分发

## 学习路径

1. 先写一个 Dart 脚本
2. 再抽成 CLI 工具
3. 最后编译分发
