# Flutter 桌面端 · 技术选型

## 推荐技术栈

| 用途 | 推荐 | 说明 |
|---|---|---|
| 框架 | Flutter Desktop | 同一套代码 |
| 窗口 | window_manager | 窗口控制 |
| 托盘 | system_tray / tray_manager | 常驻 |
| 本地 | path_provider / ffi | 文件与系统 |
| 打包 | msix / 安装包 | 分发 |

> 说明：上表为本机可落地的主流选型；「是否已安装」以各分类 README 的实测为准。

## 核心知识

- **桌面适配**：窗口尺寸与缩放
- **平台通道**：调用系统能力
- **打包**：桌面产物格式
- **复用策略**：移动代码 + 桌面适配

## 学习路径

1. 先开启桌面支持跑通
2. 再加窗口与托盘
3. 最后打包分发
