# Flutter 桌面端 · 开发计划

> 原则：**每个阶段都产出可运行、可验证的东西**，先小步跑通再逐步加深。

## 阶段一 · 跑通桌面

- **目标**：跑通
- **产出**：一个桌面窗口

- [ ] 开桌面支持
- [ ] 跑通项目
- [ ] 窗口显示

## 阶段二 · 桌面适配

- **目标**：像桌面应用
- **产出**：适配后的界面

- [ ] 响应式布局
- [ ] 快捷键
- [ ] 自定义标题栏

## 阶段三 · 系统能力

- **目标**：能干活
- **产出**：带文件 / 托盘的 App

- [ ] 文件读写
- [ ] 托盘常驻
- [ ] 通知

## 阶段四 · 打包

- **目标**：可交付
- **产出**：安装包

- [ ] 打包 msix / exe
- [ ] 图标与版本
- [ ] 分发说明

### 里程碑与验收

| 阶段 | 验收标准 |
