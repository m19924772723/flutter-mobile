# Flutter 桌面端 · 简介

> 用 Flutter 构建 Windows / macOS / Linux 桌面应用

## 能做什么

- 跨平台桌面界面
- 窗口管理与托盘
- 本地文件读写
- 打包安装程序
- 移动端代码复用

## 适合的项目

- **轻量桌面工具**：跨平台
- **内部应用**：复用移动端
- **快速原型**：界面开发快

## 本机环境

- 本机状态：⚠️ 需补装 Flutter SDK
- 工具链：需装 Flutter SDK；window_manager、system_tray
- 注意：⚠️ 需装 Flutter 并开启桌面支持

## 快速开始

```bash
flutter config --enable-windows-desktop
flutter create my_desktop
flutter run -d windows
```
