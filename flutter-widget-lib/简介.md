# Flutter 组件库 · 简介

> 打造可复用的 Flutter 组件库

## 能做什么

- 组件封装与 API 设计
- 主题与定制
- 文档与示例 App
- 多端一致性
- 发布 pub.dev

## 适合的项目

- **团队组件库**：多项目复用
- **开源组件**：对外发布
- **设计系统**：统一视觉

## 本机环境

- 本机状态：⚠️ 需补装 Flutter SDK
- 工具链：需装 Flutter；发布到 pub.dev、golden test
- 注意：⚠️ 需装 Flutter；组件库要兼顾多端一致性

## 快速开始

```bash
flutter create --template=package my_ui
flutter test
flutter pub publish --dry-run
```
