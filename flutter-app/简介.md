# Flutter 跨平台 App · 简介

> 用 Flutter 一套代码构建 iOS / Android 应用

## 能做什么

- 跨平台 UI
- 状态管理
- 网络与本地存储
- 动效与手势
- 打包上架

## 适合的项目

- **跨平台 App**：一套代码两端
- **工具类 App**：快速开发
- **内容型 App**：界面丰富

## 本机环境

- 本机状态：⚠️ 需补装 Flutter SDK
- 工具链：需装 Flutter SDK + Dart；Riverpod / Bloc、Dio、sqflite / Isar
- 注意：⚠️ 本机未装 Flutter；Android SDK 已有，装 Flutter 后可跑 Android 端

## 快速开始

```bash
flutter create my_app
cd my_app && flutter run
flutter build apk
```
