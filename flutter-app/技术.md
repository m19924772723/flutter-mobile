# Flutter 跨平台 App · 技术选型

## 推荐技术栈

| 用途 | 推荐 | 说明 |
|---|---|---|
| 框架 | Flutter | 声明式 UI |
| 语言 | Dart | AOT / JIT |
| 状态 | Riverpod / Bloc / GetX | 状态管理 |
| 网络 | Dio | HTTP 客户端 |
| 存储 | sqflite / Isar / Hive | 本地数据库 |

> 说明：上表为本机可落地的主流选型；「是否已安装」以各分类 README 的实测为准。

## 核心知识

- **Widget 树**：一切皆组件
- **状态管理**：局部与全局
- **热重载**：开发效率
- **平台差异**：iOS / Android 适配

## 学习路径

1. 先跑通 Flutter 模板
2. 再学状态与网络
3. 最后做完整 App 并打包
