# Flutter / Dart — 跨平台移动应用（需补装）

**定位**：一套代码同时出 Android / iOS 应用

**本机状态**：⚠️ 需补装 SDK

**工具链**：缺 flutter / dart；Android SDK 已就绪

**建议技术栈**：Flutter SDK、Dart

**注意**：Windows 上可开发调试 Android；iOS 出包需 Mac
