# Flutter Web 应用 · 可实现的典型功能

> 以下为该子方向可落地的功能清单，可作为选题与需求池。

## 界面

- **响应式**：适配桌面 / 移动
- **动效**：流畅过渡
- **主题**：深浅模式

## 路由

- **URL 路由**：可分享链接
- **深链接**：直达页面
- **返回**：浏览器历史

## 性能

- **首屏优化**：减少体积
- **懒加载**：按需加载
- **缓存**：静态资源

## 部署

- **静态托管**：任意静态服务
- **PWA**：可安装
- **CI 发布**：自动构建

---

> 每个功能都可独立成一个小项目，建议按「最小可用 → 好用 → 自动化」的顺序推进。
