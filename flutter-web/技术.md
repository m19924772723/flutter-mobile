# Flutter Web 应用 · 技术选型

## 推荐技术栈

| 用途 | 推荐 | 说明 |
|---|---|---|
| 框架 | Flutter Web | 同一套代码 |
| 渲染 | CanvasKit / HTML | 渲染后端 |
| 路由 | go_router | Web 路由 |
| 图表 | fl_chart | 可视化 |
| 部署 | 静态托管 | 部署简单 |

> 说明：上表为本机可落地的主流选型；「是否已安装」以各分类 README 的实测为准。

## 核心知识

- **渲染模式**：CanvasKit 与 HTML
- **首屏优化**：体积与加载
- **URL 路由**：Web 友好
- **PWA**：离线与服务端缓存

## 学习路径

1. 先把 App 编译成 Web
2. 再优化首屏与路由
3. 最后部署静态托管
