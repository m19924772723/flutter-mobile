# Flutter Web 应用 · 简介

> 用 Flutter 构建 Web 应用

## 能做什么

- 单页 Web 应用
- 响应式布局
- PWA 离线
- 与后端对接
- 跨端代码复用

## 适合的项目

- **内部 Web 工具**：复用代码
- **展示型站点**：动效丰富
- **跨端复用**：一套代码

## 本机环境

- 本机状态：⚠️ 需补装 Flutter SDK
- 工具链：需装 Flutter；CanvasKit、go_router、fl_chart
- 注意：⚠️ 需装 Flutter；Flutter Web 首屏体积较大，注意优化

## 快速开始

```bash
flutter create my_web
flutter run -d chrome
flutter build web --release
```
