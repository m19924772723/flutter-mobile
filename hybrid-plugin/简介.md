# 原生插件与平台通道 · 简介

> 编写 Flutter 原生插件与平台通道

## 能做什么

- 原生能力封装
- 平台通道通信
- 插件发布
- FFI 高性能调用
- 多平台统一 API

## 适合的项目

- **能力 SDK**：对外集成
- **硬件对接**：设备能力
- **第三方集成**：原生 SDK 包装

## 本机环境

- 本机状态：⚠️ 需补装 Flutter SDK
- 工具链：需装 Flutter；Pigeon、MethodChannel、Kotlin / Swift
- 注意：⚠️ 需装 Flutter；Android 侧可复用本机 SDK

## 快速开始

```bash
flutter create --template=plugin my_plugin
flutter pub run pigeon --input pigeons/api.dart
flutter run   # 示例工程验证
```
