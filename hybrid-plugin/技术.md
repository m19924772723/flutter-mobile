# 原生插件与平台通道 · 技术选型

## 推荐技术栈

| 用途 | 推荐 | 说明 |
|---|---|---|
| 通道 | MethodChannel / Pigeon | 类型安全通信 |
| 原生 | Kotlin / Swift / C++ | 平台实现 |
| FFI | dart:ffi | 高性能调用 |
| 发布 | pub.dev 插件 | 分发 |
| 测试 | 集成测试 | 跨端验证 |

> 说明：上表为本机可落地的主流选型；「是否已安装」以各分类 README 的实测为准。

## 核心知识

- **平台通道**：Dart ↔ 原生
- **Pigeon**：类型安全代码生成
- **FFI**：直接调用 C 接口
- **多平台实现**：Android / iOS 差异

## 学习路径

1. 先用 MethodChannel 打通一次调用
2. 再改用 Pigeon 生成
3. 最后多平台实现并发布
