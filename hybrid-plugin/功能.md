# 原生插件与平台通道 · 可实现的典型功能

> 以下为该子方向可落地的功能清单，可作为选题与需求池。

## 通道

- **方法调用**：Dart 调原生
- **事件流**：原生日志回传
- **类型安全**：Pigeon 生成

## 原生

- **Android 实现**：Kotlin
- **iOS 实现**：Swift
- **统一 API**：Dart 侧一致

## 性能

- **FFI**：直接调用 C
- **批量调用**：减少往返
- **异步处理**：不阻塞

## 发布

- **插件模板**：标准结构
- **示例工程**：可验证
- **发布**：pub.dev

---

> 每个功能都可独立成一个小项目，建议按「最小可用 → 好用 → 自动化」的顺序推进。
